Topography

CO2BatchFill uses a topography abstraction to describe the geometry of the reservoir. The GenericTopography concrete type is suitable for most use cases; custom types can be created by subtyping AbstractTopography and implementing the accessor interface.

Abstract interface

CO2BatchFill.AbstractTopography — Type
AbstractTopography

Abstract base type for reservoir topography descriptions.

Subtypes must implement:

  • get_sand_layers
  • get_grid_dimensions
  • get_grid_spacing
  • get_depth_range

Default implementations are provided for get_caprock_surface, get_coordinate_origin, and get_num_layers.

See GenericTopography for the standard concrete implementation.

source
CO2BatchFill.get_sand_layers — Function
get_sand_layers(topography::AbstractTopography) -> Vector{Dict{String,Any}}

Return the sand layers of the reservoir. Each layer Dict must have:

  • "name"::String - Layer name (e.g., "L1", "L2")
  • "top"::Matrix{Float64} - Top surface depths (nx × ny)
  • "base"::Matrix{Float64} - Base surface depths (nx × ny)
source
CO2BatchFill.get_grid_dimensions — Function
get_grid_dimensions(topography::AbstractTopography) -> Tuple{Int, Int}

Return the grid dimensions (nx, ny) of the topography.

source
CO2BatchFill.get_grid_spacing — Function
get_grid_spacing(topography::AbstractTopography) -> Tuple{Float64, Float64}

Return the grid cell sizes (dx, dy) in meters.

source
CO2BatchFill.get_depth_range — Function
get_depth_range(topography::AbstractTopography) -> Tuple{Float64, Float64}

Return the depth range (depthmin, depthmax) in meters. depthmin is the shallowest depth, depthmax is the deepest.

source
CO2BatchFill.get_caprock_surface — Function
get_caprock_surface(topography::AbstractTopography) -> Union{Matrix{Float64}, Nothing}

Return the caprock top surface depths, or nothing if not defined. Default implementation returns nothing.

source
CO2BatchFill.get_coordinate_origin — Function
get_coordinate_origin(topography::AbstractTopography) -> Tuple{Float64, Float64}

Return the (x, y) coordinate origin for the grid (e.g., UTM coordinates). Default implementation returns (0.0, 0.0).

source
CO2BatchFill.get_num_layers — Function
get_num_layers(topography::AbstractTopography) -> Int

Return the number of sand layers. Default implementation returns the length of getsandlayers(topography).

Concrete type

CO2BatchFill.GenericTopography — Type
GenericTopography <: AbstractTopography

A topography constructed from raw surface arrays, suitable for use from R or any context where dataset-specific loaders are not available.

Fields

  • sand_layers: Vector of layer Dicts with "name", "top", "base" keys
  • nx, ny: Grid dimensions
  • dx, dy: Grid spacing in meters
  • depth_min, depth_max: Depth range in meters
  • caprock_surface: Optional caprock top surface (nx × ny)
  • coordinate_origin: (x, y) coordinate origin tuple

Domain creation

CO2BatchFill.create_domain — Function
create_domain(topography::AbstractTopography, dz::Float64) -> Domain3D

Create a 3D domain from a topography definition.

Arguments

  • topography: Any AbstractTopography implementation
  • dz: Vertical grid spacing in meters

Returns

  • Domain3D: A 3D domain structure suitable for simulation
