# Contributing to CO2BatchFill.jl

Thank you for your interest in contributing! Here are some ways to get involved.

## Reporting issues

If you encounter a bug or have a feature request, please open an issue on [GitHub](https://github.com/ellingsvee/CO2BatchFill.jl/issues). Include a minimal reproducible example when reporting bugs.

## Contributing code

1. Fork the repository and create a branch for your changes.
2. Make your changes and ensure all tests pass: `julia --project -e 'using Pkg; Pkg.test()'`.
3. Open a pull request with a clear description of the changes.

## Seeking support

For questions about usage or the modeling approach, open a discussion or issue on GitHub.

## Code style

- Follow standard Julia conventions.
- Add tests for new functionality.
- Add docstrings to exported functions.
